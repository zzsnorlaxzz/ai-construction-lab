# AI 작도 실험실 · 자연어 작도

중학교 1학년 삼각형의 작도와 합동을 다루는 작도 실험실입니다. 교과서 작도 과제와 자연어 작도를 위한 프로그램입니다.

**[프로그램 실행](https://zzsnorlaxzz.github.io/construction2/)**

## 파일

- `index.html`: 프로그램 전체. 브라우저에서 열어 실행할 수 있습니다.

## 다른 작도 프로그램과의 구분

- **이 저장소 (`construction2`)**: 자연어 작도와 교과서 과제를 다루는 AI 작도 실험실
- **[construction](https://github.com/zzsnorlaxzz/construction)**: 선분·각 작도와 삼각형 작도를 두 프로그램으로 제공하는 수학 작도 교실
- **[calculator](https://github.com/zzsnorlaxzz/calculator)**: 수업용 기하 작도 시뮬레이터

서로 용도가 다른 프로그램이므로 각각의 저장소에서 관리합니다.
